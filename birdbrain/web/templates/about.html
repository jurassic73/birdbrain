How Birdbrain works

A camera watches the birdbath. A Raspberry Pi at home spots movement, snaps a burst of photos, and works out who came to visit, asking Claude only when it can't tell on its own.

It checks the camera's small video stream {{ cfg.SUB_FPS }} times a second, day and night; movement has to last a fraction of a second before anything else runs.

{# ---------- 5. Detection rules ---------- #}

When movement counts as a visit

Rim and rocks

Each frame is compared with a slowly updating picture of the empty bath. A visit starts when at least {{ pct(cfg.MOTION_MIN_AREA) }}% of the watched area changes for {{ cfg.TRIGGER_FRAMES }} frames in a row; one flicker is not enough.

{% if cfg.WATER_WATCH and zones.water %}

Open water

Water never sits still, so here it takes exactly one solid, bird-sized blob near the same spot for {{ cfg.WATER_PERSIST_FRAMES }} frames in a row. Off at night, when nothing flies in to land.

{% endif %} {% if zones.ground %}

Ground around the bath

The lawn moves all day, so here it takes one animal-sized blob that stays in view for {{ cfg.GROUND_PERSIST_FRAMES }} frames in a row and moves at walking pace: by day a ground bird ({{ pct(cfg.GROUND_MIN_BLOB) }}% of the frame), at night about cat-sized ({{ pct(cfg.GROUND_MIN_BLOB_NIGHT) }}%). Blowing leaves, rain and light changing everywhere at once are ignored.

{% endif %}

From a burst of photos to a name

  • A sharp photo {{ cfg.BURST_FRAMES }} full-size photos at {{ cfg.BURST_FPS }} per second; the sharpest{% if zones.crop %}, judged inside the crop box,{% endif %} wins. A false trigger keeps its whole burst. Night photos are infrared, so black and white.
  • The Pi looks first BioCLIP 2, an open model of living things, runs on the Pi for free. The Pi animal check {% if presence_mode != 'off' %}{{ badge(presence_mode, 'shadow' if presence_mode == 'shadow' else 'pi-only') }}{% endif %} says whether anything is in a square around the whole bowl (for ground photos, the ground crop){% if presence_mode == 'gate' %}; a photo it calls empty never leaves the house and waits under {% call admin_link("/false-triggers") %}False triggers{% endcall %} for your check{% elif presence_mode == 'shadow' %}, but for now only keeps score{% else %}, but is switched off here{% endif %}. The BioCLIP 2 species check {% if classifier_mode == 'gate' %}names sure daytime regulars itself, marked {{ badge('RPi', 'pi-only') }}{% elif classifier_mode != 'off' %}guesses the species, but for now only keeps score{% else %}is switched off here{% endif %}. Modes on {% call admin_link("/settings#local") %}Settings > Pi checks{% endcall %}, scorecards on Stats.
  • Claude Haiku sees the sharpest photo{{ ', cropped' if zones.crop }} and answers in a fixed format: kind of animal, species, how sure, how many, any other animals in the shot. "Nothing there" goes to {% call admin_link("/false-triggers") %}False triggers{% endcall %}, hidden from the gallery.
  • Claude Sonnet looks at the 3 sharpest photos together when Haiku isn't sure (mostly). Still unsure: the {% call admin_link("/review") %}review queue{% endcall %}, where you have the final say.
  • What Claude is told The photo, the date and time, night or day, your yard from {% call admin_link("/notes#camera") %}Claude's Notes{% endcall %}{% if site.location %} (in {{ site.location }}){% elif not site.scene_notes %} (not filled in yet){% endif %}, the {% call admin_link("/notes#summary") %}Lessons summary{% endcall %}{{ '' if site.lessons_summary else ' (none accepted yet)' }} and the newest {{ lesson_limit }} lessons from your corrections, word for word.
  • Cost {{ haiku }} and {{ sonnet }}. A Haiku look costs {% if avg_call >= 0.001 %}about {{ avg_call | usd }}{% else %}well under a cent{% endif %}, a Sonnet second look under a cent; the notes are cached between calls. Each visit page shows these steps under "How it was decided".

{# ---------- 10. Under the hood ---------- #}

Under the hood

  • Camera Any camera with two RTSP streams; here an inexpensive Wi-Fi camera with open-source firmware, its picture and day/night settings changed from Settings > Camera (logged, undoable).
  • Computer A Raspberry Pi on the home network runs the watcher, both Pi checks, the database and this site.
  • Software Python with OpenCV for motion, ONNX Runtime for BioCLIP 2, FastAPI and htmx for the pages, SQLite for the visits, Chart.js and Leaflet for charts and maps.
  • Privacy Photos and records stay on the Pi. Only the photos Claude is asked about leave the house (plus alert photos to ntfy and species names to the info sources). A public copy, if set up, never gets a photo where the Pi's person check fires unless you've looked and pressed Make public; it never gets your notes for Claude, and your circle checks only while Settings > Public mirror shares them.
